Measure test coverage of a contract crate via cargo-llvm-cov

Usage: soroban-testkit coverage [OPTIONS] [-- [TEST_ARGS]...]

Arguments:
  [TEST_ARGS]...  Arguments forwarded to the test binary after `--`

Options:
      --format <FORMAT>       Output format [default: text] [possible values: text, lcov, html, json]
      --no-color              Never emit ANSI color codes, here or from tools this command runs
                              (e.g. cargo). Same as setting the `NO_COLOR` environment variable
      --output <PATH>         Write the report to this path (or directory for HTML). Defaults to `lcov.info`, `coverage.json`, or `target/llvm-cov/html` by format
  -q, --quiet                 Print only results and errors; suppress advisory notes. Cannot be
                              combined with --verbose
      --fail-under <PCT>      Exit 1 if line coverage is below PCT percent (0-100). Forwarded to
                              cargo-llvm-cov as --fail-under-lines. Default: no threshold
  -v, --verbose               Print extra diagnostics (commands run, files scanned) to stderr
      --manifest-path <PATH>  Cargo.toml to target when invoking from another directory
      --open                  Open the HTML report in a browser after generating it (implies
                              --format html)
      --dry-run               Print the cargo command this would run, then exit without running it. Needs neither cargo nor cargo-llvm-cov
  -p, --package <SPEC>        Workspace packages to cover; repeat to select multiple packages
      --test <NAME>           Integration test targets to cover; repeat to select multiple targets
  -h, --help                  Print help (see more with '--help')

EXAMPLES:
    soroban-testkit coverage --format html --open
    soroban-testkit coverage --format lcov
    soroban-testkit coverage --format json --fail-under 80
    soroban-testkit coverage --fail-under 80
    soroban-testkit coverage --format lcov --fail-under 80 --dry-run
